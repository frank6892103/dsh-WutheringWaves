# spec011：主题中心可拖动

状态：已完成，随集合版本 `v0.6.0` 发布
验收日期：2026-11-08

## 目标

主题中心默认固定在页面右下角，容易挡住 DSH 的底部操作。用户应能把整个选择框拖到视口里的其他位置；松手后记住该位置，刷新页面后恢复。点击主题、切换性能档和键盘操作保持原样。

## 行为

- 拖动把手是悬浮按钮、面板顶部握把、标题和说明。主题行与「动态效果」按钮仍只响应点击。
- 移动距离小于 4 像素视为点击，按钮照常打开或关闭面板。从按钮开始的拖动结束后，这一下点击不会开关面板。
- 位置按视口像素保存为 `{ left, top }`，键名 `dsh.wuthering-waves.theme-hub-position.v1`。尚未拖动时不写存储，继续使用原来的右下角样式。
- 拖动和窗口缩放都会把按钮限制在距视口边缘 8 像素之内，避免选择框被拖丢。
- 面板跟着按钮移动，并朝剩余空间展开：靠近顶部时向下打开，靠近左侧时向右打开，高度不超过该方向的可用空间。
- 心月狐下方面板、章北海航线铭牌、若娜瓦律令牌贴在选择框上，一起拖动。打开列表时这三块铭牌隐藏，关掉后再出现。
- 爱弥斯「RESONANCE SIGNAL」与其他主题一样离开右上角功能按钮；窄屏下隐藏。

程序化读取：

```js
window.__DSH_WUTHERING_THEME_HUB__.getPosition()
```

未拖动过时返回 `null`。

## 验收

```powershell
node scripts/verify-theme-hub.mjs
node scripts/verify-registry.mjs
```

覆盖默认位置、点击与拖动区分、标题拖动、主题行不拖动、边缘夹紧、窗口变窄后拉回、以及下次加载恢复。
