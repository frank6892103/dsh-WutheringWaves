# spec005：主题插件性能极致优化

状态：已完成
验收日期：2026-08-19
目标环境：性能一般的公司云电脑、两个角色主题同时安装

## 问题与结论

两个插件虽然通过主题中心互斥挂载，但旧实现仍存在两类浪费：隐藏的主题选择面板会提前请求两套预览资源；活动主题则包含持续运行的全屏滤镜、混合、毛玻璃和大量独立动画。坎特蕾拉同时创建 5 只水母、12 个气泡、9 个星芒、8 段 HUD 波形及多层潮流/折射动画，因此卡顿明显重于爱弥斯。

本规格将“省资源”设为首次安装后的默认性能档。它保留角色立绘、主题配色、可读性和核心静态意象，同时以零持续主题动画、零实时主题毛玻璃和按需资源加载为默认预算。“完整”档仍保留原有视觉效果，可由用户显式开启。

## 优化实现

### 启动与双插件共存

- 主题选项先写入 `data-preview-url`，仅在用户首次打开主题中心时才设置 `background-image`。两个插件同时安装不再因为隐藏面板而下载、解码爱弥斯海报和坎特蕾拉立绘。
- 只有当前主题执行 `mount()` 和注入 CSS；切换性能档会事务式清理并重挂当前主题，不会让两套主题同时占用渲染层。
- 性能档保存在 `dsh.wuthering-waves.performance.v1`，默认值为 `economy`。

### 省资源渲染预算

| 项目 | 爱弥斯省资源档 | 坎特蕾拉省资源档 |
| --- | --- | --- |
| 持续主题动画 | 0 | 0 |
| 实时 `backdrop-filter` | 0 | 0 |
| 轨道/水母 | 1 个静态轨道，原为 3 个动态轨道 | 2 只静态水母，原为 5 只动态水母 |
| 非必要动画层 | 不创建面板纹理、星光、极光、网格、扫描线和底部 HUD | 不创建潮流、折射、缎带、12 个气泡、9 个星芒、声呐副环、8 段波形和 HUD 边框 |
| 图片加载 | 活动时加载背景与立绘；面板纹理不加载 | 活动时只加载 1 张本地 WebP 立绘 |

省资源档还对固定背景启用 CSS containment，去掉大面积动态滤镜和混合，并将输入区的昂贵 `:has()` 装饰限制在完整档。聊天滚动、流式输出和输入时不再持续重算这些视觉效果。

## 用户操作与 API

主题中心新增“动态效果：省资源/完整”按钮。切换后当前主题会立即按新预算重挂，刷新页面或重启 DSH 后保持选择。程序化接口：

```js
window.__DSH_WUTHERING_THEME_HUB__.getPerformance()
window.__DSH_WUTHERING_THEME_HUB__.setPerformance('economy')
window.__DSH_WUTHERING_THEME_HUB__.setPerformance('full')
```

`prefers-reduced-motion: reduce` 仍具有约束作用；即使用户选择完整档，系统减少动态效果偏好也会停用主题动画。

## 回归约束与验收

自动校验覆盖：默认性能档、性能选择持久化、活动主题重挂、无效档位拒绝、预览延迟加载、经济档 DOM 分支、CSS containment、动画禁用、主题互斥、失败回滚、资源长期缓存和构建体积上限。

```powershell
pnpm run themes:build
pnpm run themes:test
pnpm run themes:release
```

本次优化不承诺不同云桌面协议、浏览器 GPU 黑名单和宿主机负载下的统一 FPS；验收以消除默认档的持续主题绘制源和不必要资源解码为确定性指标。DSH 自身的渲染成本不在插件可控制范围内。
