# spec007：鸣潮清宵主题

状态：已完成
验收日期：2026-08-26
目标环境：`@deepseek-ai/dsh@0.1.1-rc.2`、清宵主题与现有角色主题同时安装

## 目标

新增一个可独立安装、可在主题中心互斥切换的“鸣潮 · 清宵”客户端皮肤包。主题需体现清宵的梦州剑仙气质，同时延续仓库已建立的本地素材、明暗适配、完整清理和省资源默认档约束。

## 视觉规格

- 核心意象：云海、月门、水墨远山、琴弦、万剑、青玉和篆印。
- 亮色配色：宣纸白、天青、青玉与淡金；聊天区须保留足够文字对比度，并让背景场景可辨识。
- 暗色配色：月夜靛青、青碧剑光和低亮金线；角色图降低明度，避免压过会话内容。
- 角色宣传图固定在右侧，通过渐变遮罩与主体界面融合；窄屏时向右避让，不能遮挡输入区和主题中心。
- 默认省资源档只保留静态角色图、远山、月门、云海和三柄心剑；完整档可增加九剑阵、琴弦、浮叶、剑痕和低频动画。

## 功能规格

- 独立包名：`@dsh-external/dsh-client-ui-skin-wuthering-qingxiao`。
- 主题 ID：`wuthering-qingxiao`；Body 作用域：`data-dsh-skin-qingxiao`。
- 通过共享主题中心注册，排序位于爱弥斯和坎特蕾拉之后。
- 支持官方外观、爱弥斯、坎特蕾拉和清宵之间事务式互斥切换。
- 主题卸载、禁用或切换后，必须清理自有 DOM、CSS、标题、Body 属性、`theme-color` 和观察器。
- 素材由插件本地路由提供，带内容哈希、长期不可变缓存；客户端运行时不得请求外部 CDN，也不得内嵌 Base64。
- 支持浅色/深色、`prefers-reduced-motion`、窄屏和主题中心的 `economy` / `full` 性能档。

## 分发与验收

- 根工作区增加清宵的 build/test/release 命令，并纳入联合构建、校验和发布。
- `theme-registry.json` 增加第三个唯一主题条目。
- 联合发布生成清宵 `.tgz`，更新机器可读清单、SHA-256 校验和及三主题安装说明。
- 自动校验至少覆盖包元数据、注册与清理、本地资源路由、缓存头、WebP、无 Base64、构建体积、性能档 DOM 分支、低动态偏好和预览文件。
- 生成亮色、暗色预览并进行桌面视口视觉检查。
