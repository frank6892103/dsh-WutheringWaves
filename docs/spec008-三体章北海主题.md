# spec008：三体章北海主题

> 状态：v0.3.3 已完成人物/背景分层、面部轮廓修复、真 Alpha 立绘精修、HUD 安全轨道与角色动态深化，并已安装到正式 `web` 配置

## 目标

为 DeepSeek Harness Web GUI 新增一套独立、可切换的“三体 · 章北海”主题。主题需要从角色的冷静、隐忍、远见、军人纪律与最终决断出发，同时兼顾完整动态效果、云电脑省资源模式、浅色模式和深色模式。

仓库中已有 `spec007`“鸣潮 · 清宵”主题；本主题改用独立的 `spec008` 编号、文件名和主题 ID，不覆盖既有主题。

## 设计原则

1. 不复用爱弥斯的霓虹星航框、坎特蕾拉的深海玻璃、心月狐的月苑机械或清宵的水墨云剑语言。
2. 用“舰队指挥档案”建立新的视觉系统：直角裁切、航海坐标、单向航迹、克制的朱红命令标记和低速星尘。
3. 人物视觉不采用真人演员肖像或影视剧照。原创人物从横幅中分离为真 Alpha 立绘，并另建无人舰桥背景；人物以完整头肩、制服和手部轮廓独立浮在右侧。v0.3.3 使用严格的中性色背景识别恢复眉眼、鼻尖、嘴唇、下颌、耳部和发际线，并通过面部保护区避免边缘收缩损伤五官；约 2 px 的去白边处理仅作用于头发、肩部、手臂和制服等身体外缘。
4. 亮暗模式共用铁蓝、朱红、骨白与太阳金的色相关系，通过明度和透明度重构层次，不把浅色模式当作暗色模式的简单反相。
5. 动态效果必须服务角色叙事：人物低频呼吸、冬眠档案自上而下扫描、决策环在头肩区锁定、制服节点依次确认；航迹只向前展开、跃迁线短促出现，不使用活泼弹跳或高频闪烁。
6. 《三体》识别由“三恒星混沌轨道 / 危机纪元 / 黑暗森林广播 / 水滴航迹 / 自然选择号”五组符号共同承担，避免只靠主题名称说明出处。

## 动态设计

- `beihai-portrait`：6.8 秒低幅呼吸与重心上提，强化人物存在感但保持军人克制。
- `beihai-aura-pulse`：头肩后方冷钢决策场扩张，表达冬眠后的长期判断重新上线。
- `beihai-scan` 与 `beihai-portrait-node`：冬眠档案扫描线穿过立绘，制服节点按序确认身份。
- `beihai-command-sweep`：右上三恒星、右下自然选择指令和主题中心以同一舰桥扫描节奏联动。
- `beihai-course`：九秒周期的单向航迹展开，完成后保持前进态再淡出。
- `beihai-lock`：十八秒一圈的双层低速锁定环，围绕人物头肩而非漂浮在背景空处。
- `beihai-transit`：十一秒周期的短促跃迁线，只在完整模式创建。
- `beihai-star` 与 `beihai-dust`：低幅度星点呼吸和缓慢上升的舷窗微尘。
- `prefers-reduced-motion` 或“省资源”模式下关闭所有持续动画；省资源模式只创建 12 个星点，不创建微尘和跃迁节点。

## 资产分层与面部修复

### 分层结构

- `zhangbeihai-command.webp`：最初的原创电影感构图，同时用于主题选择器预览。
- `zhangbeihai-background.png`：移除人物后的 16:9 无人舰桥、星空与地球弧光背景。
- `zhangbeihai-character-cutout-v6.png`：1024×1536 真 RGBA 人物立绘，人物与背景完全独立，可分别调节位置、亮度、对比度、动态和响应式尺寸。

### v0.3.3 面部修复原因

旧版透明提取把所有“高亮、低色差”像素都视为灰色棋盘格候选。面部右侧的暖色高光与外部背景相连后，鼻尖、嘴唇和下颌部分像素被错误设为透明；后续统一收缩 2 px 又放大了残缺。

修复方案：

1. 从完整的 `zhangbeihai-character.png` RGB 原稿重新提取，而不是在残缺 Alpha 图上补画。
2. 将棋盘格候选色差阈值从宽泛的 `45` 收紧到 `12`，只识别真正接近中性灰的背景；保留肤色中的红黄分量。
3. 继续使用边缘连通与组件面积判断，清除外部棋盘格以及手臂、身体之间的封闭背景区域。
4. 对透明边缘做颜色去污染，避免灰白底色残留到半透明像素。
5. 头发、肩部、手臂、制服和裤装使用约 2 px Alpha 内收；面部使用羽化椭圆保护区，恢复耳部、眉眼、鼻尖、嘴唇、下颌和下巴的原始蒙版，不重绘五官。
6. 输出保持 1024×1536 RGBA，Alpha 覆盖完整 `0–255`；人物轮廓总体收缩约 `0.412%`，但面部轮廓不参与强收缩。

图像生成工具仅用于尝试背景提取参考。由于生成结果改变了脸型、发型且再次烘焙棋盘格，未接入项目；正式资产使用可复现的本地蒙版修复脚本生成。

## 技术要求

- 主题 ID：`threebody-zhangbeihai`
- 插件包：`@dsh-external/dsh-client-ui-skin-threebody-zhangbeihai`
- body 标记：`data-dsh-skin-zhangbeihai`
- 本地资源路由：`/plugins/@dsh-external/dsh-client-ui-skin-threebody-zhangbeihai/assets`
- 主题可以与现有包共同安装，并由 `__DSH_WUTHERING_THEME_HUB__` 互斥挂载。
- 关闭或切换主题时必须移除样式、视觉节点、监听器，并恢复标题和 `theme-color`。
- 客户端包不得内嵌 base64 图片，生成后体积小于 100 KB。
- 资产必须分为 `zhangbeihai-character-cutout-v6.png` 真 Alpha 人物、`zhangbeihai-background.png` 无人背景和原始预览横幅，三者分别使用不可变缓存 URL；人物 Alpha 范围须为 `0–255`，禁止烘焙棋盘格、白底、浅色边缘污染或面部轮廓缺失。

## 版式安全轨道

- 普通桌面：右上 HUD 使用 `top: 7px; right: 148px` 避让 Session Log；右下指令 HUD 使用 `right: 18px; bottom: 82px`，主题中心使用 `right: 18px; bottom: 22px`。
- 宽屏（≥1500px）：右上、右下和主题中心统一对齐 `right: 24px`；右上位于标题栏下方 `top: 82px`。
- 窄屏：人物退到右侧并降低不透明度，HUD 上移避让输入区；手机宽度隐藏资料 HUD，仅保留紧凑主题入口。

## 累计修改清单

1. 文档编号从 `spec007` 调整为独立的 `spec008`，主题 ID、包名和 body 属性同步独立，避免覆盖清宵主题。
2. 建立“舰队指挥档案”视觉语言：铁蓝、骨白、石墨海军蓝、决断朱红和太阳金；亮暗模式保持同一色相关系。
3. 将人物立绘与舰桥背景彻底分层，扩大人物显示比例并移除原矩形插画框，让角色成为右侧主视觉。
4. 右上 HUD 改为三恒星混沌轨道与危机纪元链接；右下 HUD 改为自然选择号指令与前进四航向，统一参考清宵主题的安全对齐轨道。
5. 增加人物呼吸、档案扫描、决策环、制服节点、三恒星轨道、自然选择号航迹、跃迁线、星点和微尘动画。
6. 增加完整/省资源两档动态模式、`prefers-reduced-motion` 兼容、弹窗避让与窄屏降级。
7. 调整浅色主题的背景透明度、人物对比度与 HUD 明度，使人物、内容和动态在深浅主题中都可读。
8. v0.3.2 通过人物外缘 Alpha 内收清除连续白边；v0.3.3 重新提取原始蒙版并增加面部保护区，修复鼻尖、嘴唇和下颌残缺。
9. 所有图片改走插件本地路由和带内容哈希的不可变缓存 URL，客户端包不内嵌 base64 图片。
10. 正式包已构建、校验并安装到 DSH `web` 配置；使用 1280×720 与 1920×1080、深色与浅色模式进行实机检查。
